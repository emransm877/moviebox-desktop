# MovieBox Desktop 0.10.4

Make MovieBox your own with 20 themes, animated poster browsing and a cleaner
sidebar. Continue watching now uses compact cards with your actual progress;
Settings offers visual theme previews and retains playback/update preferences.

- Keep equal-sized catalogue posters filled proportionally, with artwork bound
  to its own title. Repeated hero covers are filtered, and automatic movement
  resumes after eight seconds without input.
- Improve Unicode handling, catalogue caching, compressed JSON responses and
  separation of image work from title/season requests.
- Keep navigation responsive after stalled sources, preserve compatible quality
  changes and make episode/season menus fit their contents.
- Retain playback, audio, subtitles, My list, resume, downloads and optional,
  dismissible update reminders.

## Download and install

Choose `MovieBox-Setup-0.10.4-windows-x64.exe`, or extract the complete portable ZIP
and open `MovieBox/MovieBox.exe`. Keep the `_internal` folder beside the EXE.
Compare your file with its SHA-256 checksum. Existing saved data lives outside
the installation directory and is not included in these downloads.

Target: Windows 10 1809+ x64. Native playback and the final packaged application
were checked on Windows 11 x64. Other machines and Windows 10 remain unverified.
[Windows signing details](https://github.com/emransm877/moviebox-desktop/blob/main/docs/CODE_SIGNING.md).

## Validation and limits

143 unit tests, 34 native theme/input checks, 55 control checks, 42 owned-media
checks and 25 Settings checks passed for the reviewed source. Both final native
Windows and offscreen packaged smoke checks passed, including decoded 1080p
fixture playback, subtitles, seeking, theme selection and library actions.
Those fixture checks do not certify every upstream stream or every computer.
Available titles, languages, qualities and subtitles depend on the service.
